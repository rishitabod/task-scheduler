⚡ TaskScheduler
🎓 DSA Minor Project — Priority Queue

Manage Tasks with
Smart Priority Queue

A task scheduler built using Priority Queue data structure. Tasks are automatically sorted by priority and deadline — so you always know what to do next.

🧠

Priority Queue DSA

Tasks are sorted using a Min-Heap based Priority Queue — the core DSA concept powering this app.

⚡

Smart Scheduling

Automatically surfaces your most urgent tasks. Never miss a deadline again with intelligent sorting.

🔐

Secure & Personal

Each user has their own private task list. Your data is saved in MySQL and persists across sessions.

📊

Progress Tracking

Visual progress bar and stats to track how many tasks you've completed across all priorities.

⚠️

Overdue Alerts

Tasks past their deadline are automatically flagged so you can take immediate action.

🔍

Search & Filter

Quickly find tasks by name or filter by priority level. Edit or delete tasks on the fly.

Built with Spring Boot + MySQL + Priority Queue DSA  ·  Minor Project 2026
